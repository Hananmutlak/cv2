Om webbplatsen

Syftet med webbplatsen

Denna webbplats är utformad för att hantera ett CV med fokus på arbetslivserfarenhet. Du kan:

  • Visa alla tidigare erfarenheter
  • Lägga till nya erfarenheter
  • Redigera eller ta bort erfarenheter

Teknisk information

Använda tekniker:

  • Frontend: HTML5, CSS3, JavaScript med Fetch API
  • Backend: Node.js med Express.js
  • Databas: PostgreSQL
  • Kommunikation: REST API med CORS-stöd

Databasinformation:

  • Servertyp: PostgreSQL (Hosted on Render)
  • Host: dpg-cvqo7o3e5dus73dle130-a.oregon-postgres.render.com
  • Databasnamn: dt207g_p03c
  • Hanteringsverktyg: pgAdmin 4

Slutsatser från projektet

  • Att separera frontend från backend underlättar underhåll och vidareutveckling
  • Effektiv användning av REST API i moderna applikationer
  • Utmaningar med hantering av databasanslutningar via Connection Pooling med PostgreSQL
  • Vikten av att validera data innan lagring
  • Flexibilitet vid distribution på Render med molnbaserade databastjänster
  • Vikten av SSL-inställningar för säker anslutning till fjärrdatabaser
