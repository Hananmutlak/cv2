Om webbplatsen

Syftet med webbplatsen

Denna webbplats är utformad för att hantera ett CV med fokus på arbetslivserfarenhet. Du kan:

  • Visa alla tidigare erfarenheter
  • Lägga till nya erfarenheter
  • Redigera eller ta bort erfarenheter

Teknisk information

Använda tekniker:

  • Frontend: HTML5, CSS3, JavaScript med Fetch API
  • Backend: Node.js med Express.js
  • Databas: MySQL Server
  • Kommunikation: REST API med CORS-stöd

Databasinformation:

  • Servertyp: MySQL Community Server
  • Databasnamn: cv
  • Tabellnamn: workexperience

Slutsatser från projektet

  • Vikten av att separera frontend från backend
  • Effektiviteten i att använda REST API i moderna webbapplikationer
  • Utmaningar med att hantera databasanslutningar via Connection Pooling
  • Vikten av datavalidering innan lagring
